# 專案緣起與研究目的

本專案起於一個受冠狀動脈鈣化評分啟發的問題：當影像強度受到微小擾動時，我們究竟能對最終分數及其分類作出什麼保證？閾值式評分看似只是幾個簡單步驟，卻可能同時涉及像素的啟動與排除、連通區域的形成與合併、最小元件大小，以及由最大強度決定的權重。因此，輸入的微小變化未必只帶來分數的微小變化。

這份工作將上述機制整理為一個精確的圖模型，研究指定擾動範圍內的所有可能分數、可達極值，以及分類保持不變的半徑與邊界。除了建立有限狀態表示、保留分數像集的壓縮方法與精確演算法，我們也探討取得這些保證的計算代價，釐清圖結構、權重與元件大小門檻如何共同決定問題的可解性。

這項研究的目標，是讓閾值式評分具有明確的語意、可供獨立檢查的穩健性保證，以及清楚界定的計算限制。臨床情境提供了問題的起點；本文的結論則限定於所定義的數學模型，不構成臨床效能驗證。希望這份工作能為理解不連續的影像量化方法提供一個可延伸的理論基礎。
